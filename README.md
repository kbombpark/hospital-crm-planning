# 병원 CRM 기획 자료

1stCRM을 고객 단위 CRM과 일일 가설 에이전트로 확장하기 위한 기획 문서.

- `index.html` 병원 CRM 기획 자료 (현황 진단, 벤치마크, 기능 지도, 핵심 기능, 에이전트, 규제 제약, 단계별 진행)
- `general-crm.html` 범용 CRM 제품 기획 (코어 + 업종 팩 구조)
- `competitor-analysis.html` 병원 CRM 경쟁 비교 (CRM·마케팅·재무 영역 업체 비교와 1stCRM 가치 상승 방안)
- `workflow-map.html` 워크플로 기반 기능 정의 (워크플로우 7단계, 기능 31개, 온톨로지 맵, 업체×단계 매핑, 수신 동의 요건, 해외 고객 유치)
- `pricing-plans.html` 마케팅 자동화 요금제 가안 및 기능별 비교 (라이트·그로스·프로, 홈페이지 제작비, 단계별 업그레이드 이유). 가격은 확정 전
- `homepage-score-status.html` 성형외과·피부과 184곳 홈페이지 AI 검색 점수 현황 (항목별 평균 득점, 놓친 점수, 업종별 비교)
